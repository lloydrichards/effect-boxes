# Render overlapping boxes

Use `Stack` to place boxes over one another in a fixed-size viewport. Compose
ordinary Boxes first, describe their positions with `Layer.make`, then render
with `Renderer.frame`.

Every example below is complete. After [installing the dependencies](/getting-started),
save an example as `stack.ts` and run `bun stack.ts` or `npx tsx stack.ts` with Node.
Each terminal preview shows the output of its accompanying code.

## Three bordered boxes

A and B start side by side. C moves one row down and one column right from B,
covering B's lower-right corner and its label. The dots make the uncovered viewport visible.

`x` counts columns from the left; `y` counts rows from the top. Both start at
zero. Borders are part of each box's dimensions: these boxes are 5 columns
wide and 3 rows high. C is at `(7, 2)` with `z: 1`; A and B use `z: 0`.

export const outThreeBoxes = (() => {
const a = Box.text("A").pipe(Box.pad(0, 1), Box.border("rounded"));
const b = Box.text("B").pipe(Box.pad(0, 1), Box.border("rounded"));
const c = Box.text("C").pipe(Box.pad(0, 1), Box.border("rounded"));
const background = Box.text(Array(6).fill("·".repeat(13)).join("\n"));
const stack = Stack.make(
  [
    Layer.make(background, { z: -1 }),
    Layer.make(a, { x: 1, y: 1 }),
    Layer.make(b, { x: 6, y: 1 }),
    Layer.make(c, { x: 7, y: 2, z: 1 }),
  ],
  { width: 13, height: 6 }
);
const rendered = Effect.runSync(
  Renderer.frame(stack, { preserveWhitespace: true }).pipe(
    Effect.provide(Renderer.PlainRendererLive)
  )
);
const before = Box.renderPlainSync(Box.hcat([a, b, c], Box.top));
const output = `Side by side\n${before}\n\nOverlapping\n${rendered.output}`;
return output;
})();

## Change which box is in front

Background colors show each box's full rectangle, including blank cells.
A is blue and B is amber. Their positions and dimensions stay the same in both
frames; only A's `z` changes. Labels and borders identify the boxes without
relying on color.

The first frame puts B in front. The second raises A above B, so A's right edge
cuts through B. Higher `z` wins, regardless of the layer's position in the array.

`Layer.make` defaults `x`, `y`, and `z` to zero. When two layers have the same
`z`, the later layer covers the earlier layer. Rebuild the layers and Stack
with the new depth values when your application updates.

export const outDepth = (() => {
const a = Box.text("A: blue").pipe(
  Place.make({ width: 12, height: 3 }),
  Box.border("single"),
  Box.annotate(Ansi.combine(Ansi.colorHex("#FFFFFF"), Ansi.bgColorHex("#174A78")))
);
const b = Box.text("B").pipe(
  Box.alignHoriz(Box.right, 12),
  Place.make({ width: 12, height: 3 }),
  Box.border("single"),
  Box.annotate(Ansi.combine(Ansi.colorHex("#171717"), Ansi.bgColorHex("#F2C166")))
);
const render = (aDepth) => Effect.runSync(
  Renderer.frame(
    Stack.make(
      [Layer.make(a, { z: aDepth }), Layer.make(b, { x: 6, y: 2, z: 1 })],
      { width: 20, height: 7 }
    ),
    { preserveWhitespace: true }
  ).pipe(Effect.provide(Renderer.AnsiRendererLive))
).output;
const output = `B in front (A z=0, B z=1)\n${render(0)}\n\nA in front (A z=2, B z=1)\n${render(2)}`;
return output;
})();

## Center a popup without covering the whole viewport

Build the popup, including its padding and border, before calculating its
position. This popup is 19 columns wide and 5 rows high. In a 30-by-9 viewport,
its top-left corner is `(5, 2)`. The odd horizontal gap leaves 5 columns on the
left and 6 on the right.

Use offsets on `Layer.make` to keep the layer the size of the popup. Centering
with `Place.make({ width: 30, height: 9, x: "center", y: "center" })` would
create a viewport-sized opaque Box; its surrounding blank cells would hide
the entire dashboard. These offset formulas assume the popup fits the viewport.

export const outCentered = (() => {
const width = 30;
const height = 9;
const background = Box.text(Array(height).fill("·:".repeat(width / 2)).join("\n")).pipe(
  Box.annotate(Ansi.combine(Ansi.white, Ansi.bgColorHex("#174A78")))
);
const popup = Box.text("Save changes?").pipe(
  Box.pad(1, 2),
  Box.border("single"),
  Box.annotate(Ansi.combine(Ansi.black, Ansi.bgColorHex("#F2C166")))
);
const x = Math.floor((width - popup.cols) / 2);
const y = Math.floor((height - popup.rows) / 2);
const stack = Stack.make(
  [Layer.make(background), Layer.make(popup, { x, y, z: 1 })],
  { width, height }
);
const rendered = Effect.runSync(
  Renderer.frame(stack, { preserveWhitespace: true }).pipe(
    Effect.provide(Renderer.AnsiRendererLive)
  )
);
const output = rendered.output;
return output;
})();

of text and two empty interior rows. Those empty rows still hide the dots.

including its border, is 16 columns, so the rightmost 6 columns are clipped.
Its right border disappears at the viewport edge; the box is not resized or

## Query the frame you rendered

To preserve a styled Box when adding a reactive ID, wrap the styled Box in a
Row first. `Box.annotate` replaces the annotation on its target Box.

The blue panel has a reactive ID. The amber cover has no ID and splits the
panel into two visible fragments. The uncovered cell at `(col: 3, row: 2)` hits
`panel`; the covered cell at `(col: 8, row: 2)` returns no hit. Coordinates use
the viewport origin, including borders and layer offsets.

export const outConfirm = (() => {
const styled = Box.text("ABCDEFGHIJKL\nmnopqrstuvwx\n123456789012").pipe(
  Box.border("single"),
  Box.annotate(Ansi.combine(Ansi.white, Ansi.bgColorHex("#174A78")))
);
const panel = Box.hcat([styled], Box.top).pipe(Reactive.makeReactive("panel"));
const cover = Box.emptyBox(5, 2).pipe(
  Box.annotate(Ansi.bgColorHex("#F2C166"))
);
const stack = Stack.make(
  [Layer.make(panel, { x: 2, y: 1 }), Layer.make(cover, { x: 8, y: 1, z: 1 })],
  { width: 20, height: 7 }
);
const rendered = Effect.runSync(
  Renderer.frame(stack, { preserveWhitespace: true }).pipe(
    Effect.provide(Renderer.AnsiRendererLive)
  )
);
const region = Reactive.getRegion(rendered.resolved.regions, "panel");
const fragments = Option.match(region, {
  onNone: () => "Panel not found",
  onSome: (value) => value.visible.map((fragment) =>
    `row ${fragment.row}, col ${fragment.col}: ${fragment.rows} rows x ${fragment.cols} cols`
  ).join("\n"),
});
const uncovered = Reactive.hitTest(rendered.resolved, { row: 2, col: 3 });
const covered = Reactive.hitTest(rendered.resolved, { row: 2, col: 8 });
const output = `${rendered.output}\nVisible fragments:\n${fragments}\nUncovered hit: ${JSON.stringify(uncovered)}\nCovered hit: ${JSON.stringify(covered)}`;
return output;
})();

A region retains each occurrence of an ID, its original bounds, its bounds
inside the viewport, and its visible fragments. An opaque layer can split one
region into several fragments. Fully hidden regions remain discoverable, with
no visible fragments.

Use `Reactive.hitTest` for visible interaction. Hits contain unique IDs, with
inner IDs before their ancestors. An opaque layer without a reactive ID still
blocks IDs beneath it. Occurrence keys identify occurrences within one frame.
Do not keep those keys across updates.

## Resolve once for several outputs

Use `Renderer.resolve` when several outputs or queries need the same snapshot.
Resolution requires no renderer service. Encoding requires a `FrameEncoder`.
Keep the original resolved object for encoding and hit testing. Do not copy it
with object spread or reconstruct it from its public fields; the private frame
data belongs to the original snapshot.

The two encodings below reuse one resolved Stack. They have identical text
and geometry; only the ANSI encoding retains the blue and amber backgrounds.
The built-in renderer layers supply the frame encoder required by
`Renderer.encode`. Neither encoding resolves the layers again.

export const outResolved = (() => {
const background = Box.text(Array(5).fill("·".repeat(20)).join("\n")).pipe(
  Box.annotate(Ansi.combine(Ansi.white, Ansi.bgColorHex("#174A78")))
);
const popup = Box.text("Ready").pipe(
  Box.pad(0, 1),
  Box.border("single"),
  Box.annotate(Ansi.combine(Ansi.black, Ansi.bgColorHex("#F2C166")))
);
const stack = Stack.make(
  [Layer.make(background), Layer.make(popup, { x: 4, y: 1, z: 1 })],
  { width: 20, height: 5 }
);
const program = Effect.gen(function* () {
  const resolved = yield* Renderer.resolve(stack);
  const plain = yield* Renderer.encode(resolved, { preserveWhitespace: true }).pipe(
    Effect.provide(Renderer.PlainRendererLive)
  );
  const ansi = yield* Renderer.encode(resolved, { preserveWhitespace: true }).pipe(
    Effect.provide(Renderer.AnsiRendererLive)
  );
  return `Plain output\n${plain.output}\n\nANSI output\n${ansi.output}`;
});
const output = Effect.runSync(program);
return output;
})();

## Handle unsupported content

Layer offsets and `z` values must be safe integers. Stack dimensions must be
nonnegative safe integers. The constructors throw `RangeError` for invalid
numbers.

Resolution supports nested ANSI style annotations and reactive IDs. Commands,
embedded terminal controls, arbitrary annotations, and invalid Box dimensions
fail with `FrameResolutionError`. The resolver checks hidden layers too.
Encoder failures use `FrameEncodingError`.
If independently resolved glyphs join into a different grapheme when composed,
resolution fails with `FrameResolutionError` to preserve frame coordinates.

Keep terminal commands separate from frame content. HTML frames, transparent
layers, Stack inside Box composition, and incremental redraw are deferred.
Rebuild and resolve the Stack in your existing application update loop.
