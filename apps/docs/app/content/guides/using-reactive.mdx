# Using Reactive

Track a box by ID to find its row, column, height, and width after composition. Use those positions to navigate or update an interactive terminal layout. Reactive does not run an event loop or write to a terminal.

Every fenced TypeScript example is complete. After [installing the dependencies](/getting-started), save one as `example.ts` and run `bun run example.ts` with Bun or `npx tsx example.ts` with Node. The final terminal program also needs `@effect/platform-node@^4`.

## Track a region without losing its style

`Reactive.makeReactive` replaces the root annotation. To keep a styled box, place it inside a new composition and track that wrapper. The child retains its green style.

export const outStyled = (() => {
  const styled = Box.annotate(Box.text("Ready"), Ansi.green);
  const tracked = Reactive.makeReactive(Box.hcat([styled], Box.top), "status");
  const output = Box.renderPrettySync(tracked);
  return output;
})();

## Inspect positions after layout

`getPositions` returns an Effect `HashMap`. Handle missing IDs with `Option`. The following preview shows the exact bounds of the green status text inside its border.

export const outPositions = (() => {
  const styled = Box.annotate(Box.text("Ready"), Ansi.green);
  const tracked = Reactive.makeReactive(Box.hcat([styled], Box.top), "status");
  const layout = Box.border(tracked, "single");
  const positions = Reactive.getPositions(layout);
  const bounds = Option.match(HashMap.get(positions, "status"), {
    onNone: () => "Status not found",
    onSome: (position) =>
      `row=${position.row}, col=${position.col}, rows=${position.rows}, cols=${position.cols}`,
  });
  const output = `${Box.renderPrettySync(layout)}\n${bounds}`;
  return output;
})();

Rows and columns are zero-based and relative to the top-left corner of the supplied layout. Recompute positions after resizing or changing the layout.

Use unique IDs with `getPositions`. If an ID occurs more than once, this map retains only the last visited occurrence. Zero-height or zero-width boxes, and their descendants, contribute no positions.

For overlapping or clipped layouts, resolve a frame with `Renderer.resolve` and query `Reactive.getRegion`. That API preserves every occurrence and its visible fragments. Use `Reactive.hitTest` for cells in the resolved frame. See [Render overlapping boxes](/guides/stacking-boxes) and the [Reactive API reference](/api/reactive).

## Write the targeted update to a terminal

`cursorToReactive` creates an absolute terminal cursor command from layout-relative coordinates. Those coordinates are correct only when the layout starts at terminal row zero and column zero. For another origin, add its row and column to the tracked position and pass them to `Cmd.cursorTo`.

Install the Node platform package below and save this complete program as `menu.ts`. Use an ANSI terminal at least eight columns wide and three rows tall. Run `bun run menu.ts` with Bun or `npx tsx menu.ts` with Node. It enters the alternate screen, paints the menu at the origin, and updates only the Edit row.

```sh
npm install effect-boxes "effect@^4" "@effect/platform-node@^4"
```

```typescript check showLineNumbers
import { Effect, HashMap, Option, Terminal } from "effect";
import { NodeRuntime, NodeTerminal } from "@effect/platform-node";
import * as Box from "effect-boxes/Box";
import * as Ansi from "effect-boxes/Ansi";
import * as Cmd from "effect-boxes/Cmd";
import * as Reactive from "effect-boxes/Reactive";

const menu = Box.vcat(
  [
    Reactive.makeReactive(Box.text("  File  "), "file"),
    Reactive.makeReactive(Box.text("  Edit  "), "edit"),
    Reactive.makeReactive(Box.text("  View  "), "view"),
  ],
  Box.left
);
const positions = Reactive.getPositions(menu);
const selected = Box.annotate(Box.text("> Edit  "), Ansi.bold);
const setup = Box.renderPrettySync(
  Box.combineAll([
    Cmd.altScreenEnter,
    Cmd.cursorHide,
    Cmd.clearScreen,
    Cmd.home,
  ])
);
const teardown = Box.renderPrettySync(
  Box.combineAll([Cmd.altScreenLeave, Cmd.cursorShow])
);

const program = Effect.gen(function* () {
  const terminal = yield* Terminal.Terminal;
  yield* Effect.acquireUseRelease(
    Effect.void,
    () =>
      Effect.gen(function* () {
        yield* terminal.display(setup);
        yield* terminal.display(Box.renderPrettySync(menu));
        yield* Effect.sleep("500 millis");
        const update = Option.flatMap(
          HashMap.get(positions, "edit"),
          (position) => {
            if (
              selected.rows !== position.rows ||
              selected.cols !== position.cols
            ) {
              return Option.none();
            }
            return Option.map(
              Reactive.cursorToReactive(positions, "edit"),
              (move) => Box.renderPrettySync(Box.combineAll([move, selected]))
            );
          }
        );
        yield* Option.match(update, {
          onNone: () =>
            Effect.fail(
              new Error("Edit region is missing or has different dimensions")
            ),
          onSome: (command) => terminal.display(command),
        });
        yield* Effect.sleep("500 millis");
      }),
    () => terminal.display(teardown)
  );
});

NodeRuntime.runMain(program.pipe(Effect.provide(NodeTerminal.layer)));
```

`terminal.display` writes the exact string without an extra newline. `console.log` would add a newline and move the cursor after every write. `acquireUseRelease` restores the main screen and cursor when the body succeeds, fails, or is interrupted.

Keep exclusive control of the terminal during the update. Wrapping, scrolling, or another writer can invalidate the coordinates. The dimensions check protects this ASCII example; use layout measurements rather than JavaScript string length for wide characters. To replace shorter text, pad it to the full tracked width so old characters disappear.

For input handling and repeated redraws, continue with [Select prompt](/tutorials/select-prompt). For terminal control and cleanup, see [Using Cmd](/guides/using-cmd).
