# Using Layout

Use `Layout` to arrange Boxes within an available width or height. Each example below is standalone and matches its terminal preview. Start with [Using Box](/guides/using-box) for text, borders, and alignment.

| Goal                                           | Use                        |
| ---------------------------------------------- | -------------------------- |
| Divide one row or column among children        | `Flex.row` or `Flex.col`   |
| Pass dimensions after padding to a builder     | `Container.make`           |
| Arrange repeated items in equal-width columns  | `Grid.make` or `Grid.auto` |
| Position and clip content inside an exact area | `Place.make`               |

For overlapping layers, use [frame rendering](/guides/stacking-boxes).

## Flex

Flex subtracts fixed children and gaps before distributing remaining space. `Flex.row` allocates columns, and `Flex.col` allocates rows.

- `Flex.fixed(box)` keeps the Box's dimensions.
- `Flex.grow(box, factor)` aligns or crops the Box to its allocated size. The default factor is `1`.
- `Flex.fill(builder, factor)` passes an allocated size to your builder. Your builder must return a Box of that size. Flex does not resize its result.
- `Flex.spacer(factor)` consumes allocated space without visible content.

If fixed children and gaps exceed the requested size, Flex keeps them. Use `Place` when the final dimensions must be exact.

### Push items apart

### Build content from allocated width

The progress builder returns exactly the allocated number of columns. It also handles a zero-width allocation without adding a marker.

export const outFill = (() => {
  const progress = Flex.row(
    [
      Flex.fixed(Box.text(" Progress ")),
      Flex.fill((width) => {
        const complete = Math.floor(width * 0.7);
        const marker = complete < width ? "╸" : "";
        return Box.text(
          "━".repeat(complete) +
            marker +
            "─".repeat(width - complete - marker.length)
        );
      }),
      Flex.fixed(Box.text(" 70% ")),
    ],
    63
  ).pipe(Box.border("rounded"));
  const output = Box.renderPrettySync(progress);
  return output;
})();

### Choose gaps and alignment

Both Flex functions accept `gap` and `align`. A row's gap counts columns, and its alignment controls vertical placement. A column's gap counts rows, and its alignment controls horizontal placement.

Use `Box.top`, `Box.center1`, or `Box.bottom` for a row. Use `Box.left`, `Box.center1`, or `Box.right` for a column.

## Container

`Container.make` calculates dimensions after padding and passes them to your builder. Padding can be a number for both axes or `[vertical, horizontal]`. The result enforces width, but it does not enforce height.

When you omit `height`, both `ctx.height` and `ctx.innerHeight` are `0`. The content still determines the output height. Supply a height before using `ctx.innerHeight` to allocate vertical space.

export const outContainer = (() => {
  const panel = Container.make({ width: 63, padding: 2 }, (ctx) =>
    Box.vcat(
      [
        Box.text(`outer width:  ${ctx.width}`),
        Box.text(`inner width:  ${ctx.innerWidth}`),
        Box.text(`inner height: ${ctx.innerHeight}`),
        Box.text("padding:      2 cells each side"),
      ],
      Box.left
    )
  ).pipe(Box.border());
  const output = Box.renderPrettySync(panel);
  return output;
})();

## Grid

`Grid.make` aligns each item inside a column of exactly `colWidth` columns. Wider items are cropped. A final incomplete row gets empty cells. Three 21-column cells and two one-column gaps occupy 65 columns before the outer border.

export const outGrid = (() => {
  const cards = ["Alpha", "Beta", "Gamma", "Delta", "Epsilon", "Zeta"].map(
    (name) =>
      Box.vcat([Box.text(`■ ${name}`), Box.text("  Item card")], Box.left).pipe(
        Box.pad(0, 1),
        Box.minWidth(19),
        Box.border("rounded")
      )
  );
  const grid = Grid.make(cards, { cols: 3, colWidth: 21, gap: [1, 1] }).pipe(
    Box.border()
  );
  const output = Box.renderPrettySync(grid);
  return output;
})();

### Grid options

| Option        | Meaning                                                                      |
| ------------- | ---------------------------------------------------------------------------- |
| `cols`        | Column count for `Grid.make`                                                 |
| `colWidth`    | Exact cell width for `Grid.make`                                             |
| `minColWidth` | Minimum width used to calculate `Grid.auto` column count                     |
| `maxColWidth` | Optional cap on each automatic column's width                                |
| `gap`         | `[horizontal, vertical]` for `Grid.make`; horizontal spacing for `Grid.auto` |
| `align`       | Horizontal alignment inside cells, default `Box.left`                        |
| `stretch`     | Pads items before alignment; cell widths remain exact with either setting    |

## Place content inside a fixed area

`Place.make` produces exactly the requested `width` and `height`. Content outside that area is clipped, and empty cells contain spaces. The border below is outside the 20-column, five-row area.

export const outPlace = (() => {
  const panel = Box.text("Ready").pipe(
    Place.make({ width: 20, height: 5, x: "center", y: "center" }),
    Box.border("rounded")
  );
  const output = Box.renderPrettySync(panel);
  return output;
})();

`x` counts columns from the left edge, and `y` counts rows from the top edge.
Both default to `0`. Negative offsets clip the start of the content.
For horizontal anchors, use `"left"`, `"center"`, or `"right"`.
For vertical anchors, use `"top"`, `"center"`, or `"bottom"`.
Centering uses `Math.floor((areaSize - contentSize) / 2)` on each axis,
including when content is larger than the area.

### Clip one dimension at a time

`Place.horizontal` changes only width, and `Place.vertical` changes only height. Their combined result below contains `HIJK` and `NOPQ`.

export const outPlaceClipped = (() => {

Place retains nested annotations on visible source content, including styles
and reactive regions. Added padding has no source annotations. Apply an
annotation to the resulting Box if it should cover the whole area.

Place uses the existing logical Reactive tracking API. It does not correct
pre-existing differences between rendered and tracked coordinates for centered
SubBoxes; see [the tracking alignment issue](https://github.com/lloydrichards/effect-boxes/issues/132).

Dimensions must be nonnegative safe integers. Numeric offsets must be safe
integers. Place throws `RangeError` for invalid numbers or any `Cmd` annotation
inside the source Box, even if the command would be clipped. Compose terminal
commands separately from placed content.

## Compose a dashboard

The container reserves two columns for padding. The three card widths account for their borders before Grid arranges them. The dashboard is 65 columns wide including its outer border.

export const outComposed = (() => {
  const dashboard = Container.make({ width: 63, padding: 1 }, (ctx) => {
    const cols = 3;
    const gap = 1;
    const colWidth = Math.floor((ctx.innerWidth - (cols - 1) * gap) / cols);
    const kpis = Grid.make(
      [
        { label: "Users", value: "1,247" },
        { label: "Revenue", value: "$48,290" },
        { label: "Errors", value: "23" },
      ].map(({ label, value }) =>
        Box.vcat([Box.text(label), Box.text(value)], Box.left).pipe(
          Box.pad(0, 1),
          Place.horizontal(colWidth - 2, "left"),
          Box.border("rounded")
        )
      ),
      { cols, colWidth, gap: [gap, 0] }
    );
    const header = Flex.row(
      [
        Flex.fixed(Box.text("◆ Dashboard")),
        Flex.spacer(),
        Flex.fixed(Box.text("Settings ▸")),
      ],
      ctx.innerWidth
    );
    return Box.vcat(
      [header, Box.text("─".repeat(ctx.innerWidth)), kpis],
      Box.left
    );
  }).pipe(Box.border("rounded"));
  const output = Box.renderPrettySync(dashboard);
  return output;
})();
