# Using Layout

The `Layout` module provides higher-level layout combinators built on top of
Box, inspired by CSS Flexbox and Grid. Flex, Container, Grid, and Place return
standard Box values, composable with borders, annotations, padding,
and all other Box primitives. Layer and Stack describe overlapping content for
[frame rendering](./stacking-boxes).

## Flex

Flex distributes space among children using a flexbox-style algorithm. Children
can be fixed-size, growable, or dynamically built from allocated space.

### Child Types

- **`Flex.fixed(box)`** — keeps its intrinsic size
- **`Flex.grow(box, factor?)`** — stretches to fill remaining space
- **`Flex.fill(builder, factor?)`** — receives allocated size and builds content to fit
- **`Flex.spacer(factor?)`** — invisible child that pushes siblings apart

### Horizontal Layout (Flex.row)

Use `Flex.spacer()` to push children apart, like CSS `justify-content: space-between`:

export const outRow1 = Box.renderPrettySync(
  pipe(
    Flex.row(
      [
        Flex.fixed(Box.text("◆ App Logo").pipe(Box.pad(0, 1))),
        Flex.spacer(),
        Flex.fixed(Box.text("Home  Reports  Settings").pipe(Box.pad(0, 1))),
        Flex.spacer(),
        Flex.fixed(Box.text("▸ Admin").pipe(Box.pad(0, 1))),
      ],
      65
    ),
    Box.border("rounded")
  )
);

### Proportional Splits

Grow and fill children share remaining space by factor. A factor of 2 gets
twice the space of a factor of 1:

export const outRow2 = Box.renderPrettySync(
  pipe(
    Flex.row(
      [
        Flex.fill(
          (w) =>
            Box.text("1/3 width").pipe(
              Box.pad(0, 1),
              Box.minWidth(w),
              Box.border("rounded")
            ),
          1
        ),
        Flex.fill(
          (w) =>
            Box.text("2/3 width").pipe(
              Box.pad(0, 1),
              Box.minWidth(w),
              Box.border("rounded")
            ),
          2
        ),
      ],
      65,
      { gap: 1 }
    ),
    Box.border()
  )
);

### Fill Children

Fill children receive their allocated width and build content to fit exactly.
This is useful for dynamic content like progress bars or separators:

export const outFill = Box.renderPrettySync(
  pipe(
    Flex.row(
      [
        Flex.fixed(Box.text(" Progress ").pipe(Box.pad(0, 1))),
        Flex.fill((w) =>
          Box.text(
            "━".repeat(Math.floor(w * 0.7)) +
              "╸" +
              "─".repeat(Math.max(0, w - Math.floor(w * 0.7) - 1))
          )
        ),
        Flex.fixed(Box.text(" 70% ").pipe(Box.pad(0, 1))),
      ],
      65
    ),
    Box.border("rounded")
  )
);

### Options

Both `Flex.row` and `Flex.col` accept an options object:

- **`gap`** — space between children (in columns for row, rows for col)
- **`align`** — cross-axis alignment (`Box.top`, `Box.center1`, `Box.bottom` for row; `Box.left`, `Box.center1`, `Box.right` for col)

## Container

Container provides dimension-aware building. It computes inner dimensions
after padding, passes them to your builder function, then enforces the
container width on the output.

export const outContainer = Box.renderPrettySync(
  pipe(
    Container.make({ width: 65, padding: 2 }, (ctx) =>
      Box.vcat(
        [
          Box.text(`outer width:  ${ctx.width}`),
          Box.text(`inner width:  ${ctx.innerWidth}`),
          Box.text(`padding:      2 cols each side`),
        ],
        Box.left
      )
    ),
    Box.border()
  )
);

## Grid

Grid arranges items in rows and columns with uniform column widths.

### Fixed-column Grid

export const gridCards = [
  "Alpha",
  "Beta",
  "Gamma",
  "Delta",
  "Epsilon",
  "Zeta",
].map((name) =>
  Box.vcat([Box.text(`■ ${name}`), Box.text("  Item card")], Box.left).pipe(
    Box.pad(0, 1),
    Box.minWidth(17),
    Box.border("rounded")
  )
);
export const outGrid = Box.renderPrettySync(
  pipe(
    Grid.make(gridCards, { cols: 3, colWidth: 21, gap: [1, 1] }),
    Box.border()
  )
);

<CodeExample>

```typescript
import { Grid } from "effect-boxes/Layout";

      Box.pad(0, 1),
```

### Auto-column Grid

`Grid.auto` calculates the number of columns from a container width and
minimum column width — useful for responsive layouts:

export const outGridAuto = Box.renderPrettySync(
  pipe(Grid.auto(gridCards, 50, { minColWidth: 20 }), Box.border())
);

<CodeExample>

```typescript

```

### Grid Options

| Option        | Description                                    |
| ------------- | ---------------------------------------------- |
| `cols`        | Number of columns (fixed grid only)            |
| `colWidth`    | Width of each column (fixed grid only)         |
| `minColWidth` | Minimum column width (auto grid only)          |
| `maxColWidth` | Maximum column width (auto grid only)          |
| `gap`         | `[horizontal, vertical]` spacing between cells |
| `align`       | Horizontal alignment within cells              |
| `stretch`     | Whether to stretch items to fill column width  |

## Place content inside a fixed area

`Place.make` positions content inside an area with exact `width` and `height`.
Content outside the area is clipped. Empty cells contain spaces. The result is
a normal `Box`, so you can add a border or compose it with other Boxes.

export const outPlace = Box.renderPrettySync(
  Box.text("Ready").pipe(
    Place.make({ width: 20, height: 5, x: "center", y: "center" }),
    Box.border("rounded")
  )
);

<CodeExample>

```typescript
import * as Box from "effect-boxes/Box";
import { Place } from "effect-boxes/Layout";

const panel = Box.text("Ready").pipe(
  Place.make({ width: 20, height: 5, x: "center", y: "center" }),
  Box.border("rounded")
);
```

<AnsiTerminal input={outPlace} />
</CodeExample>

`x` counts columns from the left edge, and `y` counts rows from the top edge.
Both default to `0`. Negative offsets clip the start of the content.
For horizontal anchors, use `"left"`, `"center"`, or `"right"`.
For vertical anchors, use `"top"`, `"center"`, or `"bottom"`.
Centering uses `Math.floor((areaSize - contentSize) / 2)` on each axis,
including when content is larger than the area.

Use `Place.horizontal` to change only the width, or `Place.vertical` to change
only the height. Each helper preserves the other dimension.

export const outPlaceClipped = Box.renderPrettySync(
  Box.text("ABCDEF\nGHIJKL\nMNOPQR").pipe(
    Place.horizontal(4, -1),
    Place.vertical(2, "bottom"),
    Box.border()
  )
);

<CodeExample>

```typescript
const clipped = Box.text("ABCDEF\nGHIJKL\nMNOPQR").pipe(
  Place.horizontal(4, -1),
  Place.vertical(2, "bottom"),
  Box.border()
);
// Visible content: HIJK, then NOPQ.
```

<AnsiTerminal input={outPlaceClipped} />
</CodeExample>

Place retains nested annotations on visible source content, including styles
and reactive regions. Added padding has no source annotations. Apply an
annotation to the resulting Box if it should cover the whole area.

Place uses the existing logical Reactive tracking API. It does not correct
pre-existing differences between rendered and tracked coordinates for centered
SubBoxes; see [the tracking alignment issue](https://github.com/lloydrichards/effect-boxes/issues/132).

Dimensions must be nonnegative safe integers. Numeric offsets must be safe
integers. Place throws `RangeError` for invalid numbers or any `Cmd` annotation
inside the source Box, even if the command would be clipped. Compose terminal
commands separately from placed content.

## Composing with Box Primitives

Layout functions return standard `Box` values, so they compose with all
Box operations. Here's a dashboard combining Container, Flex, and Grid:

export const outComposed = Box.renderPrettySync(
  pipe(
    Container.make({ width: 65, padding: 1 }, (ctx) => {
      const cols = 3;
      const gap = 1;
      const colWidth = Math.floor((ctx.innerWidth - (cols - 1) * gap) / cols);
      const kpis = Grid.make(
        [
          Box.vcat([Box.text("Users"), Box.text("1,247")], Box.left).pipe(
            Box.pad(0, 1),
            Box.minWidth(colWidth - 2),
            Box.border("rounded")
          ),
          Box.vcat([Box.text("Revenue"), Box.text("$48,290")], Box.left).pipe(
            Box.pad(0, 1),
            Box.minWidth(colWidth - 2),
            Box.border("rounded")
          ),
          Box.vcat([Box.text("Errors"), Box.text("23")], Box.left).pipe(
            Box.pad(0, 1),
            Box.minWidth(colWidth - 2),
            Box.border("rounded")
          ),
        ],
        { cols, colWidth, gap: [gap, 0] }
      );
      const header = Flex.row(
        [
          Flex.fixed(Box.text("◆ Dashboard")),
          Flex.spacer(),
          Flex.fixed(Box.text("Settings ▸")),
        ],
        ctx.innerWidth
      );
      return Box.vcat(
        [header, Box.text("─".repeat(ctx.innerWidth)), kpis],
        Box.left
      );
    }),
    Box.border("rounded")
  )
);
