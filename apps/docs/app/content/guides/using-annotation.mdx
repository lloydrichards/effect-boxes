# Using Annotation

Attach metadata to a box to describe its style or application data. A renderer decides how to interpret that metadata. Start with [Using Box](/guides/using-box) if you have not composed a layout yet.

Every example below is complete. After [installing the dependencies](/getting-started), save one as `example.ts` and run `bun run example.ts` with Bun or `npx tsx example.ts` with Node.

## Attach a style

`Box.text` returns `Box<never>`. `Box.annotate` returns a box whose annotation type matches the attached data. Both calls preserve the text and dimensions.

export const outBasic = (() => {
  const plain = Box.text("Hello");
  const styled = Box.annotate(plain, Ansi.red);
  const output = Box.renderPrettySync(styled);
  return output;
})();

`Box.renderPrettySync` interprets ANSI styles. `Box.renderPlainSync` produces text without styling. Neither renderer converts arbitrary application metadata into visible text.

## Attach and inspect application data

Create an annotation, attach it to a box, and inspect its data. This example explicitly turns the data into a visible label.

export const outMetadata = (() => {
  const metadata = Annotation.createAnnotation({ id: "submit", enabled: true });
  const button = Box.annotate(Box.text("Submit"), metadata);
  const data = Annotation.getAnnotationData(metadata);
  const output = Box.renderPlainSync(
    Box.vcat(
      [button, Box.text(`id=${data.id}, enabled=${data.enabled}`)],
      Box.left
    )
  );
  return output;
})();

## Replace an annotation

A box has one annotation at its root. Annotating the same box again replaces that root annotation. Combine styles with `Ansi.combine` when you want both.

export const outReplacement = (() => {
  const red = Box.annotate(Box.text("Replaced"), Ansi.red);
  const replaced = Box.annotate(red, Ansi.green);
  const combined = Box.annotate(
    Box.text("Combined"),
    Ansi.combine(Ansi.bold, Ansi.green)
  );
  const output = Box.renderPrettySync(Box.vcat([replaced, combined], Box.left));
  return output;
})();

## Nest parent and child styles

Compose a styled child inside a parent, then style the parent. The child inherits the parent's bold style and adds red. The surrounding text remains bold.

export const outNested = (() => {
  const child = Box.annotate(Box.text("Child"), Ansi.red);
  const parent = Box.annotate(
    Box.hcat([Box.text("Parent "), child, Box.text(" Parent")], Box.top),
    Ansi.bold
  );
  const output = Box.renderPrettySync(parent);
  return output;
})();

A child style can override a parent style for the same attribute, such as foreground color. This is actual nesting: the parent annotation encloses the child annotation. Styling several sibling boxes does not create a parent annotation.

## Transform annotation data

`Box.reAnnotate` transforms the root annotation data. It throws if the root has no annotation and does not transform child annotations.

export const outTransformed = (() => {
  const tagged = Box.annotate(
    Box.text("Task"),
    Annotation.createAnnotation("ready")
  );
  const updated = Box.reAnnotate(tagged, (data) => data.toUpperCase());
  const label = updated.annotation?.data ?? "missing";
  const output = Box.renderPlainSync(
    Box.vcat([updated, Box.text(`Status: ${label}`)], Box.left)
  );
  return output;
})();

## Remove annotations

`Box.unAnnotate` removes annotations from the root and all descendants. The text and layout remain unchanged. Compare the styled first line with the plain second line.

export const outRemoved = (() => {
  const nested = Box.annotate(
    Box.hcat(
      [Box.text("Parent "), Box.annotate(Box.text("Child"), Ansi.red)],
      Box.top
    ),
    Ansi.bold
  );
  const plain = Box.unAnnotate(nested);
  const output = Box.renderPrettySync(Box.vcat([nested, plain], Box.left));
  return output;
})();

## Choose an annotation module

Use [Ansi](/guides/using-ansi) for terminal styling, [Html](/guides/using-html) for HTML elements, and [Reactive](/guides/using-reactive) for position IDs.

[Cmd](/guides/using-cmd) constructs terminal control commands encoded as ANSI annotations. It uses the ANSI renderer rather than a separate Cmd renderer. Write command output directly to an ANSI terminal.

For annotation value guards, mapping, filtering, and merging, see the [Annotation API reference](/api/annotation). For renderer selection, see [Rendering](/guides/rendering).
