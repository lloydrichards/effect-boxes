# Using Box

A `Box` is a rectangle of text with a height (`rows`) and width (`cols`).
Build layouts by combining boxes, then render the result to a string.
Each operation returns a new box.

Every example below is complete. Copy an example into `example.ts` after
[installing effect-boxes](/getting-started), then run `bun example.ts` or `npx tsx example.ts` with Node.
The terminal preview for each example shows the string printed by that example.

## Create and render a box

`Box.text` creates one row per line. The longest line determines the width.
Use `Box.renderPlainSync` to get text without styling annotations.

export const outText = (() => {
  const layout = Box.text("Hello\nWorld");
  // layout.rows is 2; layout.cols is 5.
  const output = Box.renderPlainSync(layout);
  return output;
})();

`Box.char` creates a box from one character. `Box.line` removes newlines
rather than creating more rows. `Box.emptyBox(rows, cols)` reserves blank space.
This row includes a two-column gap between the star and the text:

export const outConstructors = (() => {
  const layout = Box.hcat(
    [Box.char("*"), Box.emptyBox(1, 2), Box.line("Hello\nWorld")],
    Box.top
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

## Wrap text

`Box.para(text, alignment, width)` wraps words to a column width.
`Box.left` aligns each wrapped line to the left edge.

export const outPara = (() => {
  const layout = Box.para(
    "Boxes combine text into rectangular layouts. Join boxes horizontally or vertically, align the result, and render it to a terminal.",
    Box.left,
    40
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

`Box.columns` divides wrapped text into columns with a fixed width and height.
It returns an array of boxes. Join that array with `Box.hsep` to add space
between the columns. Here each column is 20 columns wide and 4 rows high:

export const outColumns = (() => {
  const columns = Box.columns(
    "Boxes combine text into rectangular layouts. Join boxes horizontally or vertically, align the result, and render it to a terminal.",
    Box.left,
    20,
    4
  );
  const layout = Box.hsep(columns, 2, Box.top);
  const output = Box.renderPlainSync(layout);
  return output;
})();

## Compose boxes

### Join boxes horizontally

`Box.hcat` places boxes beside each other. Its alignment controls where shorter
boxes sit **vertically**. `Box.top` lines up their first rows.

export const outHcat = (() => {
  const layout = Box.hcat(
    [Box.text("Left\nsecond row"), Box.text(" | "), Box.text("Right")],
    Box.top
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

### Append two boxes

`Box.hAppend` joins two boxes at the top edge. `Box.vAppend` joins them at
the left edge. Both support `pipe`, so you can build a layout one step at a time.

export const outAppend = (() => {
  const layout = pipe(
    Box.text("Hello "),
    Box.hAppend(Box.text("World")),
    Box.vAppend(Box.text("Second row"))
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

## Align content inside a rectangle

Use `Box.left`, `Box.right`, `Box.top`, or `Box.bottom` to align an edge.
`Box.center1` and `Box.center2` both center content. If spare space is odd,
`center1` places the extra space after the content, while `center2` places it before.

This comparison centers one character in a six-column rectangle. The borders
are part of the example code and make the padding visible:

export const outCenters = (() => {
  const first = Box.border(
    Box.alignHoriz(Box.text("X"), Box.center1, 6),
    "single"
  );
  const second = Box.border(
    Box.alignHoriz(Box.text("X"), Box.center2, 6),
    "single"
  );
  const layout = Box.hsep([first, second], 2, Box.top);
  const output = Box.renderPlainSync(layout);
  return output;
})();

`Box.align` sets both dimensions. Its arguments are horizontal alignment,
vertical alignment, height, then width. Borders add two rows and two columns
outside the requested dimensions. This interior is 3 rows by 7 columns:

export const outAlign = (() => {
  const layout = pipe(
    Box.text("X"),
    Box.align(Box.center1, Box.center1, 3, 7),
    Box.border("single")
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

## Add space around a box

Movement functions grow the box rather than removing text or changing an
absolute terminal position. `moveRight` adds columns on the left, and `moveDown`
adds rows above. The border below shows the resulting rectangle:

export const outMove = (() => {
  const layout = pipe(
    Box.text("Hello"),
    Box.moveRight(5),
    Box.moveDown(2),
    Box.border("single")
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

## Truncate text

`Box.truncate(width, position)` limits each line to a width and inserts an
ellipsis where text was removed. The position selects the part to preserve.
A box that already fits is returned unchanged.

`Box.left` keeps the beginning:

export const outTruncLeft = (() => {
  const layout = Box.truncate(
    Box.text("This is a very long piece of text"),
    15,
    Box.left
  );
  const output = Box.renderPlainSync(layout);
  return output;
})();

## Attach styling annotations

A `Box<A>` carries annotations of type `A`. An annotation is metadata attached
to content. The renderer decides how to interpret that metadata.

`Box.annotate` attaches a value to the content. Use `Box.renderPrettySync` to
interpret ANSI colors and terminal commands. This example prints red text:

export const outPretty = (() => {
  const layout = Box.annotate(Box.text("Error!"), Ansi.red);
  const output = Box.renderPrettySync(layout);
  return output;
})();
